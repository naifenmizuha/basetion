# 录入完整比赛

本 Skill 只负责启动独立比赛录入会话。

1. 用户已明确确认“直接执行”时，调用 `team_game_create` 并且只传 `{"confirmed":true}`。
2. 未确认时先向用户确认；确认前绝不调用该工具。
3. 不要整理或输出 `record`、Play、payload、草稿、分区或 revision，也不要调用 `team_describe` 或 `team_modify`。
4. 工具完成后如实报告其短回执；失败或 `partial` 时不自动重试。

比赛资料会由工具启动的内部录入会话从当前用户消息继承，并按半局分块处理。
内部会话负责处理诸如 `from_base=0`、牺牲飞球和阳春本垒打等逐打席映射；外层不得展开这些数据。
