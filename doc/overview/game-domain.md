# 比赛领域模块

## 覆盖路径

- `src/internal/domain/game`

## 聚合与规则

`Match` 保存主客队、比赛时间、地点和 `scheduled`、`in_progress`、`final`、`cancelled` 状态；状态只校验枚举合法性，允许任意修正。`Lineup` 以比赛、球队、种类和编号标识一个阵容聚合，校验阵容名称、球员、棒次、条目 ID 和单一守备位置的唯一性。`Plate` 保存比赛内顺序、局次、打者、投手、投球序列、结果、垒上跑者和该打席结束后的累计比分快照。

历史 Plate 可以没有比分；新建和更新必须提供 0–65535 的主客队比分。比分是人工记录事实，不校验前后单调性、上下半局归属或相邻记录一致性。实体使用乐观版本并以 `deleted_at` 软删除。

## 服务与端口

写 `Service` 通过 `UnitOfWork` 在事务中验证球队、球员和比赛引用，创建、更新或软删除 Match、Lineup 和 Plate；删除比赛时显式软删除关联阵容和打席。读 `QueryService` 通过只读 Repository 返回恢复后的领域对象，支持比赛筛选、比赛详情、阵容、打席和当前比分；当前比分取 sequence 最大的有效 Plate，是否最终仅由 Match 状态决定。
