# 已暂存提交约定

## 背景

仓库工作区可能同时存在多个未完成的改动。需要明确“提交”的默认范围，避免 Agent 在提交时自行选择文件或把未暂存的改动带入提交。

## 变更

- 在根目录 `AGENTS.md` 的“Git 与 GitHub 操作”章节新增默认约定：用户未单独限定范围时，“提交”表示提交当前全部已暂存文件；未暂存的工作区改动不得被自动暂存。

## 影响模块

### 仓库协作规范

- `AGENTS.md`：该规则约束所有在本仓库执行 Git 提交的 Agent。提交范围由 Git 暂存区决定，Agent 仍须在提交前确认暂存内容，并继续遵守沙箱外提交和不携带无关改动的要求。

### 代码、配置、数据库与公开协议

无。本次仅修改协作说明，不改变应用运行行为、配置、数据库或工具协议。
