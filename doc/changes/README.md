# 变更记录

本目录每个 Markdown 文件对应一次用户明确要求创建的提交。编辑、调试或尚未收到提交请求时不创建记录，也不以修改任务作为记录粒度；详细规则见仓库根目录 [`AGENTS.md`](../../AGENTS.md)。

文件名格式：

```text
YYYY-MM-DD-HHMM-<short-slug>.md
```

记录模板：

```markdown
# <变更标题>

时间：YYYY-MM-DD HH:MM（本地时间）

## 背景

<为什么进行本次修改>

## 变更

- <实际完成的变化>

## 影响模块

- `<代码或文档路径>`

## 验证

- `<实际执行的命令>`：<结果>
```
