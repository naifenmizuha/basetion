# 建立仓库文档规范

时间：2026-08-14 17:25（Asia/Shanghai）

## 背景

仓库此前没有面向 Codex 的文档维护规则，也没有按模块维护的代码现状说明和按工作单元保存的变更记录。需要把两类文档纳入每次代码交付的完成条件。

## 变更

- 新增仓库级 `AGENTS.md`，规定每次代码修改必须同步维护 overview，并新增恰好一份 changes 记录。
- 明确两类文档的职责、命名方式、必填内容、例外情况和完成前检查项。
- 在 `doc/overview/` 按现有代码模块建立首份项目逻辑基线及索引。
- 在 `doc/changes/` 增加索引、记录模板和本次规范建立记录。

## 影响模块

- 代码：无。
- `AGENTS.md`
- `doc/overview/`
- `doc/changes/`

## 验证

- 文档结构与链接目标检查：通过，overview 索引中的模块文件、changes 索引和仓库规则文件均存在。
- `git diff --check`：通过，未发现空白错误。
- `go test ./...`：通过，所有现有 Go 包测试成功。
